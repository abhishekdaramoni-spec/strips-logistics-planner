🎓 B.Tech AI Practical Viva Quick Reference

Viva Notes

What is STRIPS?

Stanford Research Institute Problem Solver. Classical AI automated planning system using propositional states and operators defined by Preconditions, Add lists, and Delete lists.

Why Uniform Cost Search (UCS)?

UCS expands search nodes in order of minimum path cost g(n) using a min-heap priority queue. Because edge costs are non-negative ($c \ge 0$), the first time the goal is popped, the solution is proven optimal.

How does Goal-Stack Planning work?

It maintains a LIFO stack. Goals are decomposed backward into operators that achieve their preconditions. When an operator reaches the top with all preconditions satisfied, it executes and updates the world state.

Real Geographic Map Integration

Real GeoJSON state boundaries projected via D3.js Mercator projection. Nodes are placed using actual latitude and longitude coordinates of India's airport hubs.
